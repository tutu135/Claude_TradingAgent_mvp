# 01 — 获取并冻结中芯国际真实研究快照

**What to build:** 让用户可以从真实公开来源取得本案例需要的中芯国际研究材料，经准入、解析和 `as_of` 核验后形成可重复使用的冻结研究快照。该 ticket 同时完成实际数据获取和 `acquire-research-materials` 能力，不先建设脱离真实来源的通用取数框架。

**Blocked by:** None — can start immediately.

**Status:** done

- [x] 实际登记无需登录的公开来源，以及由用户自行注册、登录并合法下载或导出的免费资料；每份材料具有 `material_id`、`source_id`、发布者、发布时间、定位、条款入口、`usage_basis`、限制状态和内容哈希，且没有虚构来源、API、字段或数值；个人 Demo 不单独维护登录方式字段。
- [x] 需要登录的免费资料只接受用户手动取得的冻结输入；Demo 不自动注册、登录、处理验证码或绕过访问控制，也不保存账号、密码、Cookie、Token 或会话信息。付费数据库、机构席位和共享账号不默认纳入。
- [x] `SNAPSHOT_BUILD` 可以通过 Web 检索、下载、结构化数据或人工准备材料生成新快照；`DEMO_RUN` 只能读取冻结输入，不实时联网补数，也不接纳晚于 `2026-05-15T23:59:59+08:00` 的材料。
- [x] 支持带可靠文本层的 PDF、HTML、表格和文本解析；PDF 正文、表格、页码、章节、脚注及定位得到保留，页面渲染仅用于抽取和版式核对，正式溯源仍指向原始 PDF。
- [x] 不执行音频转写、图片/图表数值理解或扫描件/纯图片 PDF OCR；因此无法取得的必需事实被记录为 UNKNOWN 和 gap，而不是猜测补写。
- [x] 快照尽可能覆盖公司与证券主数据、最近三年年度和最近四个季度财务、利用率/出货/单价/结构/资本开支、政府补助、IFRS/CAS 调节、行业周期以及影响可比性的事件；每类数据都有覆盖统计或明确缺口。
- [x] 明确禁止当前处理方式、缺少来源或无法定位的材料被排除或限制；第三方原始资料不进入可分发产物，辅助抽取目录不被当作正式来源。
- [x] 快照清单记录 `snapshot_id`、`as_of`、文件/内容哈希、纳入与排除统计和个人非商业使用假设；材料变化会产生新快照身份，不静默覆盖。
- [x] 使用正常材料、`as_of` 越界材料、无定位材料和受限材料验证取数与准入行为，并证明测试数据不会冒充黄金案例数据。
