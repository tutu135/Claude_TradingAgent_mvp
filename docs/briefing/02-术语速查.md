# 术语速查（大白话版）

**给谁看**：你自己，汇报前扫一遍。

**怎么用**：不要背。先读第 0 节那一个词，再扫第 1 节（金融词，师兄也不懂，你得能讲），第 2 节（项目自造词，最常出现在代码和文档里），第 3 节按需查。

**和 `CONTEXT.md` 的区别**：`CONTEXT.md` 是给 AI 和实现者看的精确定义；这份是给人看的直觉解释。冲突时以 `CONTEXT.md` 为准。

---

## 0. 先理解这一个词：**口径**

如果只记一个词，记这个。项目**一半以上的复杂度都来自它**。

「口径」= 一个数字背后的**统计规则**。两个数字长得都像"利润"，但只要口径不同，就**不能直接比较，也不能相减**。

举个真实例子。中芯国际同一年的"利润"至少有这些版本：

| 说的是 | 口径差别 |
|---|---|
| 按国际准则（IFRS）算的利润 | 会计准则不同 |
| 按中国准则（CAS）算的利润 | 同上，数字不一样 |
| 归属于母公司股东的利润 | 剔除了子公司里别人的那部分 |
| 整个集团的利润 | 没剔除 |
| 2025 全年 | 期间：一年 |
| 2025 第二季度 | 期间：一个季度 |
| 2025 上半年累计 | 期间：半年，**不能和季度直接比** |
| 美元计 / 人民币计 | 币种不同 |
| 经审计的 / 未经审计的 | 可靠程度不同 |

**所以这个项目里的每一个数字，都必须同时携带**：单位、币种、缩放倍数（是"万元"还是"元"）、会计准则、合并范围、期间起止、审计状态。少一个，这个数字就不能参与比较。

你在报告的证据表里看到一行有 16 列，就是这个原因。**师兄如果问"为什么搞这么复杂"，答案就是这一节。**

## 1. 金融 / 会计词（师兄大概率也不懂，你要能解释）

| 词 | 大白话 | 项目里为什么在乎 |
|---|---|---|
| **投研** | 投资研究。读公开资料、分析一家公司、写成研究报告 | 这个项目在做的事 |
| **研报** | 投研的产出物，一份分析报告 | 最终产物 `report.md` |
| **IFRS / CAS** | 两套记账规则。IFRS = 国际财务报告准则（港股用）；CAS = 中国企业会计准则（A 股用） | 中芯国际两地上市，**同一年有两套财报、数字不同**。项目必须分开存，不能混 |
| **调节桥接（reconciliation）** | 公司自己披露的"从 CAS 数字怎么加加减减变成 IFRS 数字"的对照表 | 项目会**拿这张表复算一遍**，验证自己没读错。7 条里 4 条算对、3 条因为口径不匹配算不了 |
| **毛利率 gross margin** | (收入 − 直接生产成本) ÷ 收入。反映"卖一块钱货能剩几毛" | D1 维度的核心指标。实测 FY2024 是 18.0%，FY2025 是 21.0% |
| **经营利润 profit from operations** | 毛利再减掉研发、管理、销售等费用后剩下的 | 政府补助敏感性分析针对的就是它 |
| **归母净利润** | 归属于母公司股东的利润。集团赚的钱里，真正属于上市公司股东的那部分 | 调节桥接的 7 条全是这个指标 |
| **政府补助** | 政府给企业的钱（补贴、退税、项目资助等） | 半导体行业很多。**问题是**：这部分利润不是靠经营能力赚的，所以要问"剔掉它还剩多少"。这就是 D6 维度 |
| **非经常性损益** | 一次性的、不会年年有的收益或损失（卖资产、政府补助、汇兑等） | 判断"盈利改善是真本事还是运气"的关键 |
| **敏感性分析** | "如果剔掉某一项，结果会变成多少"的假设计算 | 项目**没算出来**——因为找不到能证明"可分离且确实计入了同一口径利润"的金额，所以如实写 0 条，不硬算 |
| **资本开支 CapEx** | 买设备、建厂房花的钱 | D4 维度。半导体是重资产行业，投得多不代表马上能变成利润 |
| **折旧** | 设备买来后，按年份摊到每年成本里的那部分 | 资本开支的后遗症：今年建厂，未来几年利润被折旧压着 |
| **产能利用率** | 工厂开工率。产能 100 万片、实际做了 90 万片 = 90% | D2 维度。**项目里一条可用数值都没有**，所以 D2 承重指标白名单是空的 |
| **ASP** | Average Selling Price，平均销售单价 | D3 维度唯一的承重数字，而且这一条还带着期间标注缺陷 |
| **晶圆 wafer** | 半导体制造的原料圆片，芯片刻在上面 | — |
| **8 寸 / 12 寸 / 8 寸等效** | 晶圆的尺寸。12 寸面积更大、产出更多 | **"8 寸等效"是换算过的虚拟单位，不是真实片数**。项目硬性禁止三者互换，除非原文给了换算公式 |
| **制程节点 / 28nm / FinFET** | 芯片工艺的精细程度，数字越小越先进 | 产品结构分析用（D3） |
| **财政年度 / 单季度 / YTD / TTM** | 期间类型。YTD = 年初至今累计；TTM = 滚动最近 12 个月 | **累计数和单季数不能直接比**。项目里只允许"同财年、同起点的两个累计数相减得到一个完整季度" |
| **审计状态** | 已审计 / 已审阅 / 未经审计 / 不在审计范围内 | **年报里不是所有内容都被审计覆盖**。管理层讨论、经营 KPI 属于"不在审计范围"，项目不允许它们因为"在年报里"就自动算已审计 |
| **合并范围** | 财报里包含哪些子公司 | 范围变了，两年数字就不可比 |
| **重述 restatement** | 公司事后修正以前年度的数字 | 项目保留新旧两版，不删旧的 |
| **as_of** | 本项目自定的时间线：**信息最晚公开时间**（`2026-05-15`） | **不是**财报期末，**不是**采集时间。晚于这个时间公开的资料一律不许进来——防止"用未来信息做过去的分析" |

## 2. 项目自造的流水线名词（最常出现，必须懂）

整条链的骨架叫**降级链**：**材料不会自动变成证据**，每一步都要过关，过不了就降级或隔离。

```
材料 material  →  片段 chunk  →  事实 fact  →  证据 evidence  →  发现 finding  →  质询 challenge
（一份年报）    （其中一段）   （一个数字）   （可不可以用）   （D1-D7 结论）   （反方挑刺）
```

| 词 | 大白话 |
|---|---|
| **快照 snapshot** | 把 20 份原始资料**冻起来**存一份，连同哈希值。之后所有分析只准读这一份，不许上网、不许换 |
| **冻结 frozen** | 存下来 + 记哈希值。**任何人偷偷改一个字节，哈希对不上，程序当场停** |
| **哈希 hash** | 文件内容的指纹。内容变一个字，指纹全变 |
| **材料 material** | 一份完整的资料。项目里有 20 份（13 个 PDF + 7 个网页） |
| **片段 chunk** | 材料里可精确定位的一段（某页某章某段、或某张表的若干行）。共 3,399 个 |
| **事实 fact** | 从片段里抽出来的**一条原子信息**。共 20,114 条。分两种：数值观察（4,575 条）和文本命题（15,539 条） |
| **证据 evidence** | 事实经过"信源治理"后的状态，标明**能不能拿来用**。也是 20,114 条（一对一） |
| **发现 finding** | D1–D7 七个维度各一条结论 |
| **承重（bearing）** | **本项目最重要的自造词**。某条证据直接支撑了结论的方向 = 它"承重"。<br>好比盖房子：承重墙不能拆，装饰墙可以。<br>**只有 USABLE 级证据能承重**。管理层在电话会上说"利用率显著改善"，这句话可以引用进报告，但**不能成为"利用率确实改善了"的证据**——那只是他自己说的 |
| **承重指标白名单** | 每个维度**只有名单内的指标**能承担结论方向。实测 **D2/D5/D7 名单是空的、D3 只有 1 条**——意思是这些维度的数据根本撑不起结论，项目选择**如实说出来**而不是找个数字凑上去 |
| **同源组 source group** | 同一份原始披露的不同入口算**一个**来源。同一条公告被 5 个网站转载，仍然是 1 个来源，**不能算成 5 个证据互相印证** |
| **隔离 quarantine** | 某条证据被判定完全不可用，下游禁止引用 |
| **gap（缺口）** | 一条结构化的"这里缺东西"记录。**不许用 0 或空值糊弄**，缺就登记 gap。本次运行 4,922 条 |
| **UNKNOWN vs TBD** | UNKNOWN = 资料不足，**事实**无法确定；TBD = 规则或业务选择待人拍板 |
| **治理 governance** | 判断"这份材料/这条事实能不能用、能用到什么程度"的整套规则 |
| **冻结判断输入** | 模型产出的那份发现和质询，也被冻起来当只读输入用 |
| **冻结重放 FROZEN_REPLAY** | 跑流程时**不重新调模型**，直接用上面那份冻结的判断。这样每次跑结果完全一样 |
| **证据表** | 报告里**唯一允许出现数字的地方**。一行一条证据，带全部口径信息 |
| **未绑定数字** | 出现在叙述文字里、没有对应证据行的数字。**必须为 0** |
| **运行目录** | `single-stock-demo-run/`，每次跑之前清空重建 |

## 3. AI / 检索词（师兄懂，你需要懂）

| 词 | 大白话 | 本项目怎么用 |
|---|---|---|
| **RAG** | 检索增强生成。先从资料库里搜出相关段落，再让模型基于这些段落回答，而不是凭记忆瞎编 | 项目的第 2 步 |
| **BM25** | 一种经典的**关键词**检索算法（不用 AI）。按词频和稀有度打分 | 项目的检索基线。**故意没用向量检索** |
| **embedding / 向量检索** | 把文本变成一串数字，按语义相似度搜。能搜到"意思像但用词不同"的内容 | **本项目没用**。规则写死：只有 BM25 效果是 WARN 且预先登记了具体漏召回，才允许做一次对比实验。实测 BM25 是 PASS，所以没做 |
| **分块 chunking** | 把长文档切成小段。常见做法是按固定字数滑窗 | **项目不用滑窗**，改用"结构原子"：PDF 按章节段落、表格按带表头的行组、网页按栏目、电话会按发言人轮次。因为**表格被从中间切断，单位和表头就丢了** |
| **召回 recall / 精确率 precision** | 召回 = 该找到的找到了多少；精确率 = 找到的里面有多少是对的 | 项目有一套固定验收集，硬性要求关键片段召回 100% |
| **分词 tokenization** | 把句子切成词。中文没有空格，必须切 | 项目用固定版本的中英混合分词器，把 `4Q25`、`Q4 2025` 统一成同一个期间词 |
| **幻觉 hallucination** | 模型编造看起来合理但不存在的内容 | **项目的主要防御目标**。手段：模型只能引用给定候选集里的 `evidence_id`，引用集外的直接判失败 |
| **prompt** | 给模型的指令 | 项目的 prompt 由脚本从候选集**确定性拼装**，不是人手写的 |
| **确定性 deterministic** | 同样输入必然产生同样输出 | 除了模型调用那一步，全流程都是确定性的。这就是为什么两次运行报告能字节一致 |
| **fixture** | 测试用的假数据 | 真实数据里没出现的情况（冲突、隔离），用假数据证明机制能跑 |

## 4. 状态词速查（看报告和 YAML 时会撞上）

| 状态 | 含义 |
|---|---|
| `ACQUIRED_UNASSESSED` | 材料已入库，**但还没判断可不可信** |
| `T1 / T2 / T3 / T4` | 信源等级。T1 = 公司法定披露或监管渠道（本项目 19,544 条）；T2 = 具名机构（203）；T3 = 指定媒体转载（278）；T4 = 自动摘要（89） |
| `USABLE / RESTRICTED / QUARANTINED` | 可引用**且可承重**（15,202）/ 只可引用**不可承重**（4,912）/ 隔离（0） |
| `REPORTED_FACT` | 来源直接披露的事实（19,544） |
| `MANAGEMENT_ASSERTION / GUIDANCE` | 管理层的说法 / 前瞻指引（222 / 34）——**是观点不是事实** |
| `THIRD_PARTY_VIEW` | 第三方观点（314） |
| `PASS / WARN / FAIL` | 每个阶段的运行状态。WARN = 硬条件都过了但有未解决项 |
| `SUPPORTED / MIXED / NOT_SUPPORTED / UNKNOWN` | 每个维度的结论方向 |
| `INTERNAL_DEMO_ONLY` | 分发状态，**永远是这个**——这个 Demo 不对外发布 |
| `PENDING_HUMAN_REVIEW` | 人工复核状态，**永远是这个**——没有人签过字 |

## 5. 七个分析维度 D1–D7

主研究问题是"中芯国际的经常性经营盈利能力有没有可验证的改善，证据够不够支持它可持续"。拆成七个角度：

| 维度 | 问什么 | 本次结论 | 证据分 |
|---|---|---|---|
| **D1** 盈利能力变化 | 到底改善没有？ | MIXED | 3 |
| **D2** 利用率驱动 | 是因为工厂开工率上去了吗？ | MIXED | 2 |
| **D3** 产品结构驱动 | 是因为卖的东西更值钱了吗？ | MIXED | 2 |
| **D4** 资本开支转化 | 前几年砸的钱转化成利润了吗？ | MIXED | 3 |
| **D5** 行业周期 | 会不会只是行业回暖，跟公司本事无关？ | UNKNOWN | 2 |
| **D6** 非经常项 | 会不会主要靠政府补助等一次性收益？ | MIXED | 3 |
| **D7** 可持续性 | 这个改善能持续吗？ | UNKNOWN | 2 |

**证据分 0–3**：0 = 无承重证据（强制 UNKNOWN）、1 = 单一来源或单点、2 = 两个以上独立来源组或可比跨期数值、3 = 前两者都满足且无未决冲突。

**没有总分**。`overall_score` 永远是 `NOT_APPLICABLE`——因为把七个维度加权成一个分数，等于偷偷做了投资评级，那是项目明令禁止的输出。
