# 分离采集准入与证据治理

单股票 Demo 采用“广泛采集、后续治理”的边界：满足 `as_of`、采集来源/展示发布主体/材料定位和可重复冻结底线的目标相关材料统一以 `ACQUIRED_UNASSESSED` 进入新快照。采集阶段不再要求 `USABLE`，也不判断真实性、完整性、T1–T4、内容类型、同源、冲突、隔离或证据资格；这些最终判断统一属于 `govern-and-validate-research-evidence`。

该选择扩大了候选材料范围并保留弱信源和矛盾材料供后续核验，代价是快照包含尚不可用甚至不可提取的内容。候选元数据不足时留在快照外，已确认发布时间晚于 `as_of` 是材料内容唯一的业务直接排除条件。旧 v1 保持不可变，修订边界只通过新的自包含快照生效。
